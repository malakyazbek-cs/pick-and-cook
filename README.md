# Pick & Cook

## About

Pick & Cook is a recipe management and weekly meal planning application developed in two versions: C# and Angular.

The application allows administrators to manage recipes and users to browse recipes, view cooking instructions, add recipes to favorites, and organize their meals for the week.

The database contains **40+ manually inserted recipes** with realistic sample data.

## Technologies Used

- C#
- Angular
- MySQL
- Microsoft SQL Server
- SQL

## Features

- Admin recipe CRUD (Create, Read, Update, Delete).
- Browse and view recipes.
- Cooking instructions for preparing meals.
- Add recipes to favorites.
- Organize meals in a weekly plan.
- Database containing 40+ manually inserted recipes.

## What Users Can Do

- **Administrators:** Add, view, update, and delete recipes, including their details and cooking instructions.
- **Users:** Browse recipes, follow cooking instructions, manage favorites, and plan meals for the week.

## Development Process

I designed and populated the recipe database manually using SQL, including more than 40 recipes and their related information. I then developed two separate versions of the project using C# and Angular with different database setups.

## What I Learned

- Relational database design and SQL queries.
- Managing recipe data through CRUD operations.
- Working with MySQL and Microsoft SQL Server.
- Developing applications using C# and Angular.
- Organizing application data around user needs.
